# Watch Images

Drop your watch photos in this folder and the site will pick them up automatically.

Filenames expected by config.js:

| File                          | Watch                          |
|-------------------------------|--------------------------------|
| tissot-prx-40mm.jpg           | Tissot PRX 40mm                |
| q-timex-1979.jpg              | Q Timex 1979 Reissue           |
| citizen-classics.jpg          | Citizen Automatic "Classics"   |
| timex-automatic-1983.jpg      | Timex Automatic 1983 E Line    |
| casio-mtp-1302.jpg            | Casio MTP 1302                 |

Any common image format works (.jpg, .png, .webp).
Just make sure the filename in config.js matches exactly.
